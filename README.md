# ООП

## Описание проекта:
```
Программа, которая получает информацию о вакансиях с платформы hh.ru в России, 
сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.
```

## Классы и функции, которые мы будем использовать:
```
- class Parser(ABC). Абстрактный класс для работы с API;
```
```
- class HH(Parser). Класс подключаться к API и получать вакансии;
```
```
- class VacanciesComparisons. Класс для работы с вакансиями, проверяет: 
   - Указано название вакансии, 
   - Корректность ссылки,
   - Сравнения вакансий по зарплате,
   - Описание вакансии является непустой строкой,
   - Формирования списка вакансий и преобразование его в словарь;
```
```
- class SavingInfoVacancies(ABC). Абстрактный класс, для добавления вакансий в файл;
```
```
- class JsonInfoVacancies(SavingInfoVacancies). Класс для работы с JSON-файлами вакансий:
   - Методы добавления и сохранения списока вакансий в JSON - файл,
   - Метод удаления вакансии по критерию;   
```
```
- Функция user_interaction для взаимодействия с пользователем:
   - Поиск вакансий по ключевому слову,
   - Сортировка N вакансий по зарплате,
   - Поиск вакансий по ключевому слову в описании;   
```
